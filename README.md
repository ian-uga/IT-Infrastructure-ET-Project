# ET Pitch - Self Healing Networks
What is it
Self-healing networks are a communication system designed to automatically detect, isolate, and recover from problems and issues without requiring human intervention. For example, when a node or a link fails, the network reroutes data traffic through different paths, ensuring everything stays connected. This makes it extremely important for critical infrastructure, such as power grids, hospitals, transportation, and emergency services, where the failure of any of these services would have severe consequences.
